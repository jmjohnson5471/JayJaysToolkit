# DeploymentDesigner v2

This version does not rely on browser download/export behavior.

It runs as an interactive PowerShell tool and exports:

- autounattend.xml
- deployment-profile.json
- deployment-plan.txt

Default output:

Desktop\JayJaysDeployment

Install:
Copy `DeploymentDesigner` into `JayJaysToolkit\Plugins\`, then click Reload.
