WindowsDeployment Plugin for JayJaysToolkit

Install:
Copy the WindowsDeployment folder into:

JayJaysToolkit\Plugins\

Then click Reload.

Tools included:
- Unattend > Local Autounattend Wizard
- Unattend > Open Schneegans Web Generator
- Source > Download Update Schneegans Source
- Source > Open Local Generator Folder
- Templates > Open Autounattend Templates Folder

Privacy:
The Local Autounattend Wizard runs locally and does not send entered values to the internet.
The source downloader uses the internet only to download the public GitHub source.
The web generator opens the external website and should be treated as an internet-based tool.
