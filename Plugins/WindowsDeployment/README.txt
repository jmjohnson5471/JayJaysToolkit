WindowsDeployment Plugin v2.0

Install:
Copy the WindowsDeployment folder into:

JayJaysToolkit\Plugins\

Then click Reload.

Main tool:
Unattend > JayJays Unattend Builder GUI

Features:
- Local GUI
- Preview XML button
- Export XML button
- Open Templates button
- Open Schneegans button
- Runs locally. Values are not sent to the internet.
