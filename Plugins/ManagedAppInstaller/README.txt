ManagedAppInstaller Plugin for JAYJAYs IT Platform

Copy ManagedAppInstaller into:
JAYJAYsITPlatform\Plugins\

Then click Reload.

Included:
- Winhance
- Sysinternals Suite
- WizTree
- Rufus
- PuTTY

Portable apps are stored under the platform PortableApps folder, not Desktop.
Edit Config\apps.json to add more apps.
