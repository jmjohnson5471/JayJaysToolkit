# SoftwareRepositoryManager Plugin

Copy `SoftwareRepositoryManager` into:

```text
JAYJAYsITPlatform\Plugins\
```

Then click Reload.

Use:

```text
Software Repository > Software Repository Manager GUI
```

This lets you pick a flash drive, local folder, or network share. It installs local/private installers first and falls back to winget for public apps if enabled.
