# Example Software Repository Layout

Put this folder structure on a USB drive, local folder, or network share:

```text
Software/
  Chrome/ChromeSetup.exe
  7-Zip/7z.exe
  Adobe Reader/AcroRdrDC.exe
  VLC/vlc.exe
  Firefox/Firefox Setup.exe
  Greenshot/Greenshot-INSTALLER.exe
  Notepad++/npp.exe
  Private App/setup.exe
```

Edit `Config/apps-hybrid.json` to change filenames and silent install arguments.
