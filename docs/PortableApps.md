# Portable Apps

JayJaysToolkit now stores downloaded portable tools under:

```text
PortableApps/
```

This avoids writing tools to the user's Desktop, which can fail when Desktop is redirected to OneDrive or does not exist.

Current managed folders include:

- PortableApps/Sysinternals
- PortableApps/WizTree
- PortableApps/CrystalDiskInfo
- PortableApps/HWiNFO
- PortableApps/PuTTY
- PortableApps/WinSCP

Use plugin tools to download and launch portable apps.
